现行版本：2026-10-22。依据用户本日要求，参照“构建科研领域脉络”讨论优化原周报；本版替代此前宽泛的现行筛选优先级。历史期次、日期衔接和证据规范保留。每次运行重新读取本文件、研究背景、任务配置与索引，不沿用旧提示词中的冲突主题优先级。

## 目标与问题结构

核心问题：极端天气如何改变海上运行，以及由此产生哪些后果。周报首先服务对核心领域已有认识、最近直接先例和真实知识缺口的持续掌握，再保留少量有明确联系的探索。围绕五条问题分支组织，而非按技术名词堆叠栏目：

1. 暴露与约束：气旋、风浪、预报、港口关闭和运行限制如何界定实际可观测暴露。
2. 个体船舶行为：避险、改道、航速、等待及其决策时钟和异质性。
3. 系统空间重组与相遇压力：交通流重新分布、航道和港口网络、拥挤、多船交互及尺度依赖。
4. 运行后果：能耗与排放、运输延误、服务连续性和经济后果；区分直接观测、代理指标和模型估计。
5. 恢复与适应：恢复路径、重复扰动、调整成本和适应行为；区分恢复描述与机制或因果证据。

AIS、遥感、因果推断、深度学习等作为跨问题的方法/数据标签，不作为独立问题分支。选文必须说明它改变了哪个问题的认识。与主线没有清晰连接的热门研究不用于填充篇数。

## 检索与筛选

优先检索气旋/极端天气与航运运行的直接邻近文献，再扩展到可明确迁移的交通、港口、网络、排放或灾害机制研究。同步查最新论文、预印本、直接先例的前向/后向引文以及核心作者团队的连续成果。基础文献补课少量单列，标明原发表日期与补入理由，不冒充本周进展，也不计入新文献篇数。

双语检索词按问题组合，不要求所有词同时出现：
- 灾害/约束：热带气旋、台风、飓风、极端天气 / tropical cyclone, typhoon, hurricane, extreme weather, wind, wave, forecast。
- 行为/数据：AIS、船舶行为、改道、航速、等待、气象航线 / AIS, vessel behavior, rerouting, speed, waiting, weather routing。
- 系统/后果：海上交通、网络韧性、港口扰动、相遇与碰撞风险、排放、延误、恢复 / maritime traffic, network resilience, port disruption, encounter pressure, collision risk, emissions, delay, recovery。
每条检索式选取必要概念组并保留替代词；同时沿直接先例引文链补漏，避免过窄交集漏检。

期刊声望、科学增量、可观测性和实现成本分别评价。Nature、Science、PNAS及相关子刊继续覆盖，但不得因此漏掉更直接的海运、交通、港口、海洋、气象和风险领域专业期刊。方法文须连接实际问题和独立验证。使用出版社、原文、作者数据代码库和权威索引；新闻公众号仅作线索。核实题名、DOI、类型、首次在线日期和更正状态。预印本单列、说明未同行评议，通常不超过2篇，正式发表后保留同文献版本关系。

每期通常精选3–5篇实质相关的新文献，其中1–2篇精读；这是控制阅读负担的弹性范围，不是配额。没有足够高质量结果时少报，并说明检索范围与未找到的内容。探索区只保留少量与主线存在可说明联系的研究，明确标为“探索”，不挤占直接邻近工作。

## 阅读与证据链

每篇给出英文题名、中文短题、期刊、类型、首次在线日期、DOI、来源链接、所属问题分支、方法/数据标签和实际阅读范围。摘要级阅读明确标注，不推断未读方法细节。区分原文事实、作者主张、我们的独立判断及尚不能判断之处。

精读至少回答：
- 它与哪些最近直接先例最接近，新增了什么；不能只称“首次”或“新方法”。
- 核心结论依赖哪张图、哪张表、哪个对照或方法段；给出可定位的证据锚点。
- 数据、比较单位、暴露/结果时钟和验证怎样支持结论；有哪些竞争解释或反例。
- 结论适用边界是什么，哪些机制或因果解释仍未建立。
- 对一般研究问题的认识属于支持、修正、挑战或无直接影响，并说明理由；不公开映射到用户未发表的具体结果或内部主张。
- 公开数据/代码和最小核验条件是什么。数据状态区分“原文声明公开 / 已核实入口 / 已取得样例 / 待确认”，说明独有观测、受限资料、模型和较大计算依赖。阅读不足时如实列未知。

继续区分环境危险、人口暴露、风险指标、模型健康负担和实测健康结局；涉及地表温度、近地气温、人体热应激时分别定义；夜灯停电代理、再分析和生成结果均说明独立验证边界。不要把年度渔获当短时生物量、风机停机当居民停电、风险指标当实测健康结局。

## 周报结构与知识积累

正文以“本周什么认识发生变化”开头，随后给出精选与精读、少量探索/基础补课（有则列）、领域脉络更新建议和回忆问题。以读者可消化为准，不设必须填满的字数；重点尽量简明但证据链完整。

对本期涉及的核心主题，维护暂定的3–5篇最近邻文献列表，标注各文献的关系、已知增量和缺口；作为报告或本期元数据中的“科研地图更新建议”。最近邻同时考虑“问题相近”“数据/方法相近”“其他场景中机制相近”三种关系；无变化时沿用已核对列表，不必每周完整重建。地图空白表示“当前知识未核对”，不等于学术空白。只使用可公开的文献证据，不复制私有研究台账、不建立新仓库、不自动修改其他科研地图。必要时指出列表仍不完整，不为凑数编造关系。

有证据时增加最多1条团队研究走向：通常以同一团队约3篇相关连续成果说明问题、方法或数据的延续和转变，附出处并区分事实与推断。没有足够连续证据则省略，不凭一篇论文或作者名单推断团队战略。

结尾提出2–3个回忆/比较问题，帮助读者主动比较先例、证据和边界。不在本期正文、附件或通知中提前附答案；用户回答或明确索取后再反馈。可提出最多2个待查新的研究问题，写明直接先例、潜在增量、关键未知与最小检查；换模型或扩地区本身不构成独立贡献。周报只提供线索与证据，立项、计算和Codex任务另由研究总控决定。

按此格式先运行4期后建议回顾相关性和阅读负担，不自动停用、不自动改期、不另建监控任务。没有新指令时继续按本配置执行。
